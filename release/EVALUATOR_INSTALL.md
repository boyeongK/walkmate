# 산책메이트 Android 앱 — 설치 및 체험 안내

평가용 Android 앱입니다. **Android 폰**에서 아래 순서대로 설치해 주세요.

## 1. APK 설치

1. 첨부된 **`app-debug.apk`** 파일을 Android 폰으로 전송 (메일, USB, 카카오톡 등)
2. 파일을 탭해 설치
3. **출처를 알 수 없는 앱** 허용이 필요하면 설정에서 허용 후 다시 설치

## 2. 실행 전 확인

- **인터넷 연결은 필요 없습니다.** APK 안에 데모 데이터가 포함되어 있어 서버/와이파이 없이도 동작합니다.
- 첫 실행 시 데모 계정을 선택하거나 새 계정을 만들어 체험할 수 있습니다.

## 3. 체험 방법

1. 앱 실행 → **체험 계정 선택** 또는 **새 계정 만들기**
2. **반려동물 프로필** 등록
3. **AI매칭** 탭에서 궁합 측정
4. **홈**에서 추천 산책 짝 확인
5. **이력** 탭에서 완료된 산책 기록 확인 (데모 데이터 포함)

### 데모 계정

| 이름 | 반려동물 |
|---|---|
| 김지수 | 몽이 (말티즈) |
| 박서준 | 코코 (푸들) |
| 이하늘 | 보리 (골든리트리버) |

## 4. 문제 발생 시

| 증상 | 조치 |
|---|---|
| Failed to fetch / 로딩 실패 | 앱 완전 종료 후 재실행 (오프라인 데모 모드) |
| 설치 불가 | Android 8.0 이상, 저장공간 확인 |
| 화면이 비어 있음 | 1분 후 재시도 (서버 기동 대기) |

## 서비스 개요

- AI 기반 반려동물 산책 짝 매칭
- 자유 채팅 없이 선택형 요청·상태 버튼으로 약속 조율
- 산책 후기 및 이력 관리
